# Collection, display, and storage

The starter museum has three stands: one protected stand and two public stands. The tutorial toaster starts on the protected stand and stays there until its first income dollar. After that, the owner can store it or replace it with another owned exhibit; any item on the protected stand is safe and earns half its base rate. The museum has ten safe storage slots. Stored items earn $0/min and are outside the future player-raid target set. Only available items on public stands are eligible for future raids; PvP is currently disabled, so there is no live player theft yet. The owner must be online for a future raid. The server-side `RaidTransferLocked` gate blocks exhibit moves during an active raid; the raid service must set and clear it when raids are implemented.

Each stand has a short physical marker and a proximity prompt that opens a readable stand-rules panel. Protected exhibits use a pulsing blue stand glow; public exhibits use a pulsing gold glow. All displayed items have a rarity outline and scaled ambient sparkles. The Collection screen shows the same stand meanings and a dismissible guide the first time it opens during each session. Public stand text says raids are coming until player theft is enabled.

The version-4 profile separates `exhibits` (currently owned item types), `displaySlots` (currently earning), `publicDisplayApproved` (permission to expose an item), and `collectionIndex` (permanent unique discoveries). The collection list is sent only to its owner; it is not placed on server-replicated Player attributes. A newly delivered public type fills an empty public stand immediately and is approved for that stand. When both public stands are occupied, it goes into safe storage with approval off. Existing displayed public items are approved during migration; previously stored items remain unapproved. Automatic mode fills the two public stands with the highest-income **approved** available types. Manual mode lets the owner place any owned item on the protected stand or either public stand. Storing an item removes its approval and income; an occupied stand can be replaced without deleting either owned type. The protected stand always earns half the placed item's base rate.

Storage capacity is derived from museum tier using the provisional 10/20/30/40/50-slot capacity table. Only tier 1 is playable now; Task 19 will implement larger museums and measured upgrade prices. A full storage record rejects a new unique delivery without deleting an existing item or clearing the carry. The present catalog has 12 unique types, so the starter museum's 3 displays plus 10 storage slots can hold every current type. Duplicates still pay the existing one-time salvage reward; duplicate copies are not stored or traded in this build.
